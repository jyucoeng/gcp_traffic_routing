# netMonitor 交付总结（已与当前代码校对同步）

> 对应仓库目录：`gcp_traffic_routing/netMonitor/`
> 本文与 `traffic_ctrl.sh` 当前实现逐项校对，路径/默认值/行为均已同步。

---

## 一、部署参数（环境变量，未设置取默认值）

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `PLATFORM` | 平台标识（建议小写）；内置特殊处理 gcp/oracle（oracle 自动停用 firewalld/ufw，TG 通知含 CPU 行）；其他任意标识可用 | `gcp` |
| `LIMIT` | 流量上限 GB，超限触发封网。**无默认值，部署必须显式指定**，缺省直接报错；`0`/`-1`=无限制 | 无（必填） |
| `STAT_MODE` | 计费口径 `in/out/min/max/sum`，**所有平台统一默认 sum（无平台分派）**；超限判断按此口径计得的当月字节 | `sum` |
| `SSH_PORT` | 封网后仍双向放行的 SSH 端口（**填 VPS 内部 sshd 实际监听端口**，与外部 NAT 端口无关） | `22` |
| `DNS_SERVERS` | 封网后放行的 DNS，按地址族自动分流；留空自动选（IPv4/纯 IPv6 各一套默认） | 自动 |
| `LOG_RETENTION_DAYS` | 流量监控日志保留天数：每月 1 号只保留最近 N 天，删除更早的行 | `7`（0/-1=保留全部） |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | TG 凭据（可选）；两者均非空才启用通知，**AES-256 加密落盘不明文** | 空 |

> 常量 `AUTHOR`（默认 littleDoraemon）/ `VERSION`（与仓库根 VERSION 文件一致）为部署期常量，随 conf 落盘、菜单与两份 heredoc 副本统一读取展示。

## 二、部署后生成的文件（VPS 上）

| 文件 | 类型 | 作用 |
|------|------|------|
| `/root/traffic_ctrl.sh` | 部署器本地副本 | 封网断外网后仍可离线运行 `edit`/`set-tg`/重新部署 |
| `/root/traffic_routing/check_traffic.sh` | 运行时副本（heredoc 生成） | 每 5 分钟 cron：当月上下行累计 + 超限判定 + 断网(超限)通知 |
| `/root/traffic_routing/reset_network.sh` | 运行时副本（heredoc 生成） | 每月 1 号 cron：清理日志(按保留天数) + 解封 + 重置统计 + 归档 + 恢复通知 |
| `/root/traffic_routing/netstat.sh` | 独立流量统计脚本 | nezha 式：读 `/proc/net/dev`，排除虚拟网卡，上下行分开月度增量，无 vnstat 依赖 |
| `/etc/traffic_routing/netMonitor.conf` | 运行时配置（0600） | PLATFORM/LIMIT/STAT_MODE/SSH_PORT/DNS/HAS_V*/LOG_RETENTION_DAYS/INTERFACE/加密凭据 |
| `/etc/traffic_routing/netMonitor.key` | TG 凭据 AES 密钥（0600） | 卸载时保留（覆盖式重装复用，免重配 TG） |
| `/var/log/traffic_monitor.log` | 流量监控日志 | check 每 5 分钟追加；每月 1 号按 `LOG_RETENTION_DAYS` 保留最近 N 天 |
| `/var/log/network_reset.log` | 重置日志 | reset 操作记录 |
| `/var/lib/traffic_monitor/state` | 封网状态机 | MONTH/STATE/BLOCKED_*/RESTORED_TIME/USED_*（当月流量快照） |
| `/var/lib/traffic_monitor/netcount` | 流量月度累计 | MONTH + 当月上行/下行字节（由 netstat.sh 持久化） |
| `/var/lib/traffic_monitor/archive` | 月度流量档案（长期留存） | 每月 reset 前把上月最终 TX/RX 追加一行，一行一月 |

### `state` 两种格式（一眼区分）

- **已恢复（当前正常）** → `STATE=normal`，`RESTORED_TIME` 非空，`USED_*` 为恢复后当月快照（重启周期初为 0，随后由 check 刷新为当月实际值）：
  ```
  MONTH=2026-10
  STATE=normal
  BLOCKED_TIME="2026-09-30 05:38:15"
  BLOCKED_TX="852091"
  RESTORED_TIME="2026-10-01 00:00:02"
  USED_STAT_MODE=sum
  USED_LIMIT=500
  USED_TX=0
  USED_RX=0
  USED_BAL=0
  ```
- **正在封网中（超限双向封死）** → `STATE=blocked`，`RESTORED_TIME` 为空，`USED_*`=触发封网当次判定的口径/上限/当月累计/计费流量：
  ```
  MONTH=2026-09
  STATE=blocked
  BLOCKED_TIME="2026-09-17 05:38:15"
  BLOCKED_TX="852091"
  RESTORED_TIME=""
  USED_STAT_MODE=sum
  USED_LIMIT=0.001
  USED_TX=852091
  USED_RX=0
  USED_BAL=852091
  ```

> `USED_TX/RX/BAL` 是**「当月流量快照」**而非历史值：reset 归零当月累计后随之归零（5 分钟后 check 刷新）；上月的最终值已归档到 `archive`。

## 三、子命令一览（入口分派）

| 子命令 | 作用 |
|------|------|
| `bash traffic_ctrl.sh` （无参数） | 完整部署流程（覆盖式：先 uninstall 清旧物再完整部署） |
| `bash traffic_ctrl.sh edit` | 交互式菜单：平台 / 上限 / 口径 / SSH 端口 / DNS / TG 凭据 / 日志保留天数，改完统一加密落盘 |
| `bash traffic_ctrl.sh config` | 查看当前配置（TG 凭据掩码显示，保留前后可见部分） |
| `bash traffic_ctrl.sh set-tg` | 更换 TG（`TELEGRAM_BOT_TOKEN=xxx TELEGRAM_CHAT_ID=yyy` 环境变量读取，AES-256 重加密） |
| `bash traffic_ctrl.sh clear-tg` | 停用并清除 TG 凭据 |
| `bash traffic_ctrl.sh del` | 卸载：清理 crontab 本脚本调度 / 运行时脚本 / conf / 日志；**保留密钥 key 与月度档案 archive** |

> `del` 只清理本脚本自己的部署物：crontab 用 grep 剔除 `check_traffic.sh|reset_network.sh` 行（保留其他任务），iptables 由运行时 reset 处理，卸载时不动宿主其他规则。

## 四、脚本行为要点

### 流量统计（nezha 式，无守护进程）
- `netstat.sh` 读 `/proc/net/dev`，排除 `lo/docker*/veth*/br-*/virbr*/tun*/tap*/vbox*/dummy*`，对其余物理网卡分别按 RX(第2列)/TX(第10列) 求和；
- 与上次快照求差得增量，分别累加到当月累计（`/var/lib/traffic_monitor/netcount`）；快照回绕/重启时增量归零重计；
- 跨月自动清零；每月 reset 额外 `--reset` 显式初始化。

### 封网/解封
- 超限时创建自家链 `TRAFFIC_BLOCKED`：放行 ESTABLISHED/SSH(入/出)/DNS/ICMP/lo，链内兜底 DROP；在 INPUT/OUTPUT/FORWARD 最顶部各插一条带注释跳转（`-I 1`），IPv4/IPv6 按 `HAS_V4/HAS_V6` 分别用 iptables/ip6tables；
- 不动全局默认策略（`-P`）、不清空其他链，卸载时只删带本脚本 comment 的跳转（兼容旧版裸跳转）+ `-F/-X` 自家链；
- oracle 平台部署时与每次 check 运行时都兜底停用 firewalld / ufw。

### 日志与档案
- `check_traffic.sh` 每次运行把简略状态追加到 `/var/log/traffic_monitor.log`（终端显示精确值）；
- `reset_network.sh` 每月 1 号按 `LOG_RETENTION_DAYS`（默认 7）用 awk 按行首日期截断，只保留最近 N 天（`0`/`-1`=保留全部）；
- 月度最终流量在 reset 前追加到 `archive`（格式：`月份 TX=... RX=... mode=口径 blocked=状态`）。

### TG 通知（可选）
- 超限通知标题：`🎮 {PLATFORM} 流量报告（流量超限通知）`，触发当月首超限时发 1 次（STATE 未 blocked 才发）；
- 恢复通知标题：`🎮 {PLATFORM} 流量报告（网络恢复通知）`，reset 时仅当上月 STATE=blocked 且 TG 启用才发；
- 本机 IP 多来源探测：`ip-api.com` → `ipwho.is` → `ipify` → 本机网卡地址兜底；IPv4 打码 `a.b.***.d`、IPv6 保留首尾；
- 仅 oracle 显示 CPU 行（aarch64/arm → ARM；型号含 AMD/EPYC → AMD）。
